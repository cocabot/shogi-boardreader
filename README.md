# shogi-boardreader

iPhoneで**将棋本のPDFと自由将棋盤を同じ画面に表示する**ための、依存を抑えた静的Webアプリです。

## できること

- 上側に端末内のPDF、下側に将棋盤を表示
- 中央の仕切りをドラッグして表示割合を変更（50:50へワンタップ復帰）
- PDFのページ送り、ページ指定、拡大・縮小、幅合わせ
- 横スワイプによるPDFページ送り（横スクロール中は誤作動しない）
- 将棋盤のタップ移動とドラッグ移動
- 駒取り、持ち駒、駒打ち、成り・不成
- 待った / やり直し / 盤面反転 / 初期局面
- 盤面状態と分割比率を端末内の localStorage に保存
- iPhone Safariの「ホーム画面に追加」を想定したスタンドアロン表示

## 使い方

1. WebサイトをiPhoneのSafariで開く
2. 「PDFを開く」から購入済みPDFを選ぶ
3. 下側の盤で本の手順を並べる
4. 必要なら中央のバーを上下へドラッグする

将棋盤は**読書・検討用の自由盤**です。合法手判定、王手判定、二歩判定などはあえて強制していません。書籍の途中局面や変化図を素早く再現する用途を優先しています。

## PDFの扱い

選択したPDFはブラウザ内で読み込み、アプリ独自のサーバーへアップロードしません。表示には Mozilla PDF.js (pdfjs-dist) をCDNから読み込んでいます。

## ローカル実行

ES Modulesを使っているため、file:// ではなくHTTPサーバーから開いてください。

    python3 -m http.server 8000

その後、ブラウザで http://localhost:8000 を開きます。

## 配布

静的ファイルだけなので GitHub Pages / Vercel / Netlify 等にそのまま配置できます。
